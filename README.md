# Rússia × Ucrânia — História em Contexto

Site educativo sobre o contexto histórico, as causas, a cronologia e os impactos da guerra entre Rússia e Ucrânia.

## Como visualizar
Abra `index.html` no navegador.

## Publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie todos os arquivos e a pasta `assets`.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`, depois salve.

O site é estático: não precisa de Node.js, banco de dados ou etapa de compilação.
